## Слайд 5 — Диагностика дефектов и Big O

Пример: `for (Item a : items) { for (Item b : items) { if (a.id().equals(b.id())) { merge(a, b); } } }`

- **Сложность фрагмента** — оценивается (в примере O(n²)).
- **Дефект:** повторная обработка одинаковых пар.
- **Риск:** рост времени при увеличении входа.
- **Рекомендация:** индексировать элементы по id (Map).

Что видит участник: строку кода и узел графа; объяснение найденной проблемы; оценку сложности метода или фрагмента; вариант исправления с ожидаемым эффектом.

«Диагноз должен быть проверяемым, а не только красивым».
